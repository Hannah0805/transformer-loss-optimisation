# Reproducibility Checklist

## Run the final model

From the project root, use Python 3.10 or later. The Stage 5 model and tests were executed with Python 3.13.

~~~sh
python -m pip install -r requirements.txt
python -m analysis.stage4_assumption_based_v2.run
python -m src.validate_final_report
python -m unittest discover -s tests -v
~~~

- [x] The driver ran using the assumption-based v2 settings. It regenerated byte-identical numerical CSVs.
- [x] The reported circuit, flux, loss and mass quantities at the baseline and medium minimum were independently checked. The audit also verified all 1,107 rows and the three scenario minima.
- [x] The passing set contains 251 candidates. All outcomes are determined by the 1.50 T and 22.0 V RMS tests alone.
- [x] The medium baseline and candidate use identical coefficients and the same 100 VA load model.
- [x] Four saved figures take their data from the v2 CSV files. The plot generator checks grid cells, bar heights and scenario coordinates.
- [x] All 14 automated tests passed.
- [x] The Word report was rendered to PDF from the same document source. All pages and numbered equations were inspected and both files reopened for verification.
